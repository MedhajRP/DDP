Reliability flags for the robust posterior approximations (rules: posterior_checks.py, section 5)
UNRELIABLE = the posterior is not determined to the precision at which it is used, or the covariance
is not the Laplace posterior; CAUTION = a diagnostic warns, but the posterior was stable in the checks run.
A BO run gets the worst flag of its fits. Unflagged does not mean verified: the restart, jitter and
mode checks exist only for the 80 sensitivity datasets (gaussian, student_t, sym10, down20; seeds 0-9).

Rules:
  Laplace-t        unreliable covariance fallback used (clipped W; not the Laplace posterior)   [checked on: all fits]
  Laplace-t        unreliable min eig(B) < 1e-04 (near-singular Hessian)   [checked on: all fits]
  Laplace-t        caution    1e-04 <= min eig(B) < 1e-02   [checked on: all fits]
  Laplace-t        caution    warm- and cold-started mode searches differ (d_mu > 1e-03)   [checked on: 80 datasets]
  VI-t             unreliable inner loop at the fitted theta not converged or with an ELBO decrease   [checked on: all fits]
  VI-t             caution    second fixed point from a cold start (|dELBO| > 1e-06); unreliable if the cold start has the HIGHER ELBO   [checked on: all fits]
  Laplace-t, VI-t  unreliable variance changes by more than a factor exp(0.1) when the jitter goes 1e-6 -> 1e-8   [checked on: 80 datasets]
  all              caution    optimum more than 0.1 nats worse than the best of 18 starts   [checked on: 80 datasets]
  all              unreliable ... and this changes RMSE by more than 10% or Cov_f by more than 0.05   [checked on: 80 datasets]
  Study B          unreliable BO run with at least one covariance fallback (n_fallback > 0)   [checked on: all runs]
  Study B          caution    VI-t BO run with an inner loop not converged within max_inner   [checked on: 126 re-run runs]
